# Tuesday, Oct 27, 2026: First program on real hardware, Git for TwinCAT

**Status:** First working TwinCAT program on real EtherCAT I/O (a light switch). The project is under Git and pushed to its own public repo.

## Done
- Worked through options for linking the Beckhoff system to a Rockwell/Logix system for the capstone: TwinCAT as an EtherNet/IP adapter (TF6280), Ignition as a middle layer, an EK9500 coupler, or an EL6652-0010 terminal (ruled out at about $700). A USB-to-Ethernet adapter covers most of the extra-port needs.
- Planned splitting the system across computers: a lab PC runs the runtime and EtherCAT master, and the laptop handles engineering and HMI. Learned the EK1100 has no processor or runtime of its own (unlike a Beckhoff CX embedded PC).
- Package Manager feed setup failed on a lab PC. It was a Windows permissions problem writing to `C:\ProgramData\Beckhoff\TcPkg`, not a bad password. Needs Run as administrator.
- **Built and ran the Light Switch project:** `Light := Switch;` in Structured Text, with an EL1008 input driving an EL2008 output. Fixed four problems along the way:
  1. `AT %I*` / `AT %Q*` variables weren't linked to the physical channels
  2. A VMware driver (vmx86.sys) conflicted with TwinCAT's real-time kernel
  3. No runtime license (used a 7-day trial)
  4. Then it ran: Switch TRUE drives Light TRUE
- **Put the project under Git:**
  - Moved it out of a full OneDrive folder to `C:\TwinCAT-Projects`
  - Installed Git for Windows with winget
  - Wrote a TwinCAT `.gitignore` and cleared build files out of tracking
  - Set my Git identity with the GitHub no-reply email
  - Pushed to a new public repo, `TwinCAT-Light_Switch`, signing in through the browser
- Learned a PowerShell shortcut: typing `powershell` in File Explorer's address bar opens it in that folder.
- Started cleaning up OneDrive (full, and syncing a 565 GB Desktop folder). Plan is to move keepers to Google Drive and turn off folder backup.
