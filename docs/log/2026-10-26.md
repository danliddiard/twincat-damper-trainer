# Monday, Oct 26, 2026: New PC, IT blockers, first rack scan

**Status:** The lab Pro Micro with the Intel NIC is blocked by domain security policy, so I moved the EtherCAT master to my personal laptop and scanned the rack. Trainer design started.

## Done
- Confirmed the three Dell Pro Micro QCM1250 lab PCs (ROBO-PC26-LAB07/LAB08 and one more) have Intel I219-LM network chips. Checked the hardware ID (VEN_8086&DEV_550C) in Device Manager against Beckhoff's supported list.
- Planned the full install list for the new PC so IT only has to come out once: TwinCAT Standard (XAE + XAR), TF6100 OPC UA Server, TF6701 IoT Communication (MQTT), TF6420 Database Server, and TE1300 Scope View as optional.
- Moved to a Pro Micro and reinstalled the Beckhoff software. Hit two walls:
  - This newer I219-LM revision wasn't recognized by TwinCAT's driver list (Install button grayed out).
  - The PC is domain-joined with virtualization-based security, Secure Launch and an App Control policy enforced by Group Policy. Those block the TwinCAT real-time runtime and driver install. Hyper-V itself was confirmed off.
- Wrote IT a full fix list (VBS/Secure Launch removal, driver allowlisting, Intel driver install, kernel debug off) and proposed a standalone non-domain Pro Micro as an alternative.
- Git practice: added a branch ruleset on `main` (require a pull request, block force pushes and deletions), signed VS Code into GitHub so it can push, and fixed a log file missing its `.md` extension with `git mv`.
- Upgraded my personal laptop to TwinCAT 4026 (Package Manager). Smart App Control flagged an unsigned TwinCAT resource file, which turned out to be cosmetic.
- Connected the laptop to the EK1100 (top port, X1 IN), installed the real-time driver on the Intel port, fixed a wrong device type in the scan (EtherCAT Automation Protocol instead of EtherCAT Master), and scanned the rack:
  - EK1100 coupler
  - EL1008 (8 digital inputs)
  - EL2008 (8 digital outputs)
  - EL7342 (2-channel DC motor terminal with encoder inputs)
  - EL9011 end cap
- Started the blower/damper/ball trainer design in a "mini book": since the lab is unlikely to get an analog card, a Cognex In-Sight 7200 camera replaces the analog height sensor, and the EL7342's PWM output through an RC filter makes a 0-10 V fan command. Includes bench tests, an I/O map, a five-program PLC layout, a six-state state machine, and a phased build plan.
