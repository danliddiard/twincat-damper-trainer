# Wednesday, Oct 28, 2026: Light Switch project running on the CP6606 panel

**Hardware:** Beckhoff CP6606 panel PC (Windows CE 7, TwinCAT 3.1.4024) as the controller, my Dell laptop (XAE 4026.27) as the engineering station.

**Status:** Working. A button on the EL1008 turns on a light on the EL2008, with the program running on the panel's own runtime. This proves the panel can act as the EtherCAT master for the bench.

Full step-by-step record: [troubleshooting/2026-10-28-light-switch-cp6606.md](../troubleshooting/2026-10-28-light-switch-cp6606.md)

## Done
- Added a bidirectional ADS route from the laptop to the panel (CP-2AE6A6, 192.168.1.50).
- Retargeted the Light Switch project from 4026.27 to 4024.79. Windows CE tops out at 4024, so this is the only path for this panel. Installed 4024 support, then picked the version before opening the project.
- Worked on a separate `Target-4024` branch so `main` keeps the working 4026 version.
- Switched the build platform to TwinCAT CE7 (ARMV7) to match the panel's ARM CPU.
- Built clean (0 errors, 0 warnings).
- Fixed the runtime license. The panel clock was set to 2006, so a fresh trial license showed as "issued in the future." Set the clock and re-activated, and the license went valid (good until about Nov 5).
- Mapped the panel's ports by MAC address: LAN1 (X102) is the laptop link, LAN2 (X103, labeled EtherCAT) runs the I/O through Beckhoff's CCAT chip.
- Tracked the EtherCAT "no communication" problem down to a bad Ethernet cable, plus the cable briefly being in the EK1100's X2 (OUT) port instead of X1 (IN).
- Rescanned the I/O (EK1100, EL1008, EL2008, EL7342, EL9011), relinked `MAIN.Switch` and `MAIN.LIGHT`, activated, downloaded, and tested.

## Lessons
- When EtherCAT frames go out and nothing comes back, check the cable and the EK1100 X1 link LED first. About 1.5 hours went to adapter settings before the cable was swapped.
- On an old Windows CE panel, check the clock before generating a license.
- A version switch or an I/O rescan drops variable links. Plan to relink afterward.

## Blockers
- None for the panel. The original lab station PC still needs TwinCAT Standard and an Intel NIC, but the CP6606 is now a working alternative.
